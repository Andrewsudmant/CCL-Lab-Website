# Gate 2–3A scope

## In scope

- Automated-publication governance with explicit disclosure and deterministic withholding controls.
- Canonical many-to-many relationships among themes, projects and publications.
- Theme 6 migration to Canadian climate policy and a documented Theme 5 audit.
- Verified initial lab profile, project and publication records where authoritative evidence exists.
- Modular discovery adapters, query packs, normalization, deduplication, event clustering, classification contracts, evaluation and safe publication staging.
- A bounded retrospective pilot using available public adapters; captured fixtures where credentials are missing.
- A unified Research Watch, public methods/limitations page, theme cross-listings and responsive review.
- Scheduled/manual workflow scaffolding and production-ready static packaging without public deployment.
- Context and owner-review ZIP packages.

## Out of scope

- Public production deployment, DNS, analytics, subscriber collection or merging to `main`.
- Continuous Bluesky firehose or Jetstream ingestion.
- Circumventing paywalls, robots restrictions, licences or source terms.
- Publishing title-only inference as a substantive summary.
- Automatically changing code, prompts, schemas, source policy, governance or disclosure language.
- A comprehensive bibliography without a confirmed ORCID export and metadata reconciliation.
- Claims about project funding, partners, dates or outputs that cannot be publicly verified.
