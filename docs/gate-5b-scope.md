# Gate 5B scope

## In scope

- Preserve and publish the existing Gate 0–5A Git history to a feature branch and reviewed pull request.
- Reconcile publications through ORCID, DOI registries, publishers and institutional repositories; retain unresolved records separately.
- Make fixture/AI disclosure reflect actual provenance.
- Implement and test cross-source clustering, provider-native OpenAlex diagnostics, strict mocked Responses handling, cost controls and prompt-injection resistance.
- Add a protected, manually dispatched artifact-only live benchmark and a separately guarded private-staging write job.
- Prepare, but do not treat as final, the mixed-source owner calibration generator.
- Build locally, inspect responsive pages and package a shareable governance handoff.

## Out of scope

- Requesting, discovering, displaying or storing an API key.
- Any paid API call before owner merge, manual dispatch and `live-benchmark` environment approval.
- Public deployment, production hosting, DNS, analytics or subscriptions.
- Automatic publication from the first live benchmark, or staging writes enabled by default.
- Merging the feature branch to `main`.
- Treating captured fixtures as current discovery results or the final owner calibration set.
