## Open locally

Unzip the archive, then open `rendered-site/index.html`. If browser security settings prevent local assets from loading, serve the folder with:

```bash
python3 -m http.server 8765 --directory rendered-site
```

and open `http://127.0.0.1:8765/`. No API key or network discovery is required.
