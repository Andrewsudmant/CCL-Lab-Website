# Gate 5G public internal-language audit

Audit date: 28 August 2026

## Visible public result

The root rendered site was parsed as visible text with script and style content excluded. No visible page contains:

- `Gate 5`, `Gate 5D`, `Gate 5E`, `Gate 5F`;
- `owner-approved` or an owner-review/handoff package reference;
- `record ID`, `YAML` or `Codex`;
- source-audit phrases such as “Verified relationship based on”, “publisher abstract centres” or “institutional full-text record supports”.

Public Work source lists now contain external publisher, repository, project and tool links only. Internal decision sources remain stored in Work YAML as `owner-approved-programme` records but are filtered from public source lists. Current programme evidence status uses factual public language rather than internal approval labels.

The public Current Conversations methods page replaces “strict schemas” with “required fields and deterministic controls.” The complete bibliography retains public metadata provenance because that information is meaningful to readers; governance documents and audits remain outside Quarto render, public search and sitemap.

## Non-public retained evidence

Earlier Gate labels, owner approvals, review packages, fixture descriptions, source-verification rationales and record identifiers remain in `docs/`, `reports/`, controlled YAML/JSON and Git history. Their retention supports traceability and does not make them public copy.
