Date: 2026-08-14

## Programme-level decisions

Theme status describes the maturity of the lab programme. Themes 1, 2, 3 and 5 are
established. Themes 4 and 6 are developing. Theme 4 is now supported by a cautious,
owner-approved current project without claiming results. Theme 6 remains a developing
programme and has no invented project.

Relationship to the lab is separate from thematic relationship. A foundational prior
project may be core work for a theme, and a current project may relate to several themes.
